# 🌟 Rhea Rivera — Modern 2025 Portfolio  
A fully animated, responsive, and interactive personal portfolio website built using **HTML, CSS, and JavaScript**.  
Packed with smooth animations, glassmorphism UI, scroll reveals, theme toggle, particles, floating shapes, and a modern developer profile.

---

✨ Features
🎨 UI/UX & Styling

Dynamic gradient background animation

Glassmorphism components (cards, buttons, overlays)

Neon circular profile border

Fully responsive on desktop, tablet, and mobile

Smooth scroll + section reveal animations

⚡ Interactive JavaScript Features

Typewriter effect for hero section

Light/Dark theme toggle (saved in LocalStorage)

Scroll reveal animations

Animated skill-progress bars

Floating shapes + particles animation

Parallax hero movement

Contact form with validation + message simulation

## 🛠️ Technologies Used

### **Frontend**
- HTML5  
- CSS3 (Glassmorphism + Animations)  
- Vanilla JavaScript  
- Google Fonts (Poppins, Inter)  
- Font Awesome Icons  

### **UI/UX**
- Responsive design  
- Soft gradients, neon effects  
- Smooth transitions
